# Visuels Google Play

- Icône : 512 × 512.
- Présentation : 1024 × 500.
- Trois captures : 1080 × 1920, interface réelle exécutée dans Chrome avec capteurs simulés (−0,8° / +1,1°), zéro de calibration simulé et dimensions par défaut. Aucune capture physique Android. Le badge du navigateur peut différer de celui de l’APK natif.
- Régénération : lancer Vite sur le port 4174, puis node scripts/prepare-play-assets.mjs (PLAYWRIGHT_MODULE et CHROME_EXECUTABLE optionnels).
